Epic H: landscape mockups (class B, 320×240)

Offband theme, Modern look, shown at 1.25×. The design of record already draws every screen in landscape: the status bar runs the full width, a 48 px rail replaces the tab bar on the left, and content is 272×220. It also sets the landscape values: rows 28–30 px, hints hidden, Nodes 5 rows, keyboard keys 24×25, sheets start right of the rail, logo 40 px. Those screens are built from it as drawn. What follows is only the screens we added in Epics D–G and L, which were drawn portrait-only. Values are examples; the bullets are the behavior to build. Owner-approved 2026-10-19 ("I'm happy with the layout"), with the radar's zoom buttons in the strip as drawn.
