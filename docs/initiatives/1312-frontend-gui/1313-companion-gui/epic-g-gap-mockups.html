Epic G: mockups for Settings and boot

Offband theme, Modern look, native 240×320 shown at 1.25×. Settings, Radio, Messages & alerts and Display follow ObScreen as drawn; the edit sheets, the discard prompt, the nine screens drawn only as one line in the spec, and the boot screen's real content are here, with the defaults the owner approved on 2026-10-17. Values are examples. The bullets are the behavior to build.

  • Each row is recorded as its setup phase finishes; the screen reads them.
  • A failed radio halts boot (as the plan says), so the screen never shows a failed radio row.
  • The boot line shows only after an unclean reset; a clean boot leaves it out.
