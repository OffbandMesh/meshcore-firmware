Offband theme, Modern look, shown at 1.25×. Portrait (class A: the V4 TFT) unless marked; landscape (class B: R8, T-Deck) gives the same screens beside the rail, with no on-screen keys when a keyboard is present (mockup 2, #1727). For the owner

1 · Letter case in hashtag names. The key comes from the name exactly, so #QueenCityCon and #queencitycon are different channels. A: lowercase as it's typed, so everyone lands on the same channel (recommended). B: keep exactly what was typed.

2 · Leave and Channel key (mockups 8–9). Build them with Add, or Add alone first? Without Leave, a full list of 40 can only be cleared from the phone.
