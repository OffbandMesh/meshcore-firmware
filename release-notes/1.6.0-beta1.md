**Pre-release, for testers.** 221 commits since beta7. The app shows `1.6.0-beta1-1.17.0` once a
device is upgraded.

### The headline: Offband runs on a color touch screen

The Heltec V4 TFT and the V4-R8 TFT now run a full on-device interface. Not a status readout — an
interface you use instead of reaching for your phone.

Home and Lock screens, Chats with a conversation view, a Nodes list you can search with the
keyboard or a letter wheel, a Map tab with a radar view of what is around you, and Settings. It is
LVGL on a DMA-driven ST7789 panel with a touch driver written for this firmware, and the panel was
moved off the radio's SPI bus so drawing and the radio stop competing.

Messages are kept on the device and survive a reboot, written to flash in slices so the interface
does not stall while it saves. Your own messages carry their delivery state and a "heard xN" count.
You can compose on the device with the on-screen keyboard, set notifications per channel, and turn
a screen sideways — every screen has a landscape layout, and the panel, the touch mapping and the
layout all follow Display > Rotation together.

An SD card on the panel's bus gives the device an archive that counts what it holds, survives a
hot-swap, and takes a crash's program counter and backtrace so a failure leaves evidence behind.

**Both GUI images are published with this release.**

### Every color display gets the color Offband lockup

If your board has a color panel, it now boots to the Offband lockup in color rather than a
monochrome stand-in — the ST7735 panels and the rest, with the art sized to the space each panel
actually has instead of one size stretched across all of them.

### LilyGo T-Deck

The T-Deck's hardware is supported: GT911 touch, the physical keyboard and the trackball, the
keyboard backlight following the screen, and the radio sharing SPI2 through RadioLib. Digits 1
through 4 start a canned reply.

**The T-Deck image is not published in this release.** The code is in and the environment builds in
CI; the image follows once it has had bench time.

### Heltec V4-R8, with the SAW filter

Full support for the R8 board: FEM and LNA runtime control, TX LED control to the same standard as
the earlier boards, and a power-off path that actually cuts FEM power rather than leaving it drawing.
There is a WiFi+MQTT observer environment for it, diagnostic builds, and the board is in the CI
matrix and the release list — so a change that breaks it fails before a tag, not after.

Diagnostic builds for the Heltec V4 (R2) are also here.

### Queen City Con badge

The badge makes sound. Settings > Tones gives you a picker that plays a tone before you keep it,
six chimes, and eight slots for tunes you write on the badge itself — typed in and checked before
they save. Channels can carry their own tune, so you can tell which one is talking without looking.
The phone app can push a tune into a slot.

GPS now has three power modes — Off, On and Power-save — measured rather than estimated. That is
the answer to beta7's note that a fitted GPS module held power the whole time it was enabled and
cost you most of a week of battery.

The front LED shows traffic over unread instead of sitting solid-on, with the heartbeat moved to the
module LED so the badge's own LED is free for what you care about. A fresh badge comes up already
holding the conference channels and names itself from the last five of its BLE MAC, so two badges in
a room are never the same node. `#test` and `#echo` are quiet out of the box.

A badge with no keyboard fitted can get out of Settings again.

### The beta7 known issue is fixed

**A USB companion no longer streams fewer contacts than it declares.** A RAK 4631 declared 350 and
streamed 344 or 345. `writeFrame` refusals went unchecked when the TX FIFO filled, so whole frames
vanished with nothing reported.

Four things changed: the stream's cursor advances only when the frame was actually sent,
`isWriteBusy()` reports the transport instead of a constant false, a committed frame is finished
rather than retried behind itself, and an abandoned stream now says so on a stock build — not only
in a debug image. That last one matters most: the failure was silent, and silence is what let it
ship twice.

### Security

**A malformed packet could overflow a stack buffer.** MACThenDecrypt accepted ciphertext that was
not block-aligned. It now rejects it.

### Version reporting

`ver`, `version` and the companion device-info field now all report the same Offband-first
`<offband>-<stock>` string. They could previously disagree with each other, and a build with no
reachable tag could present itself as a plausible stock version rather than admitting the stamp was
missing.

### Take note before you flash

- **The default radio preset is now the US standard: 910.525 MHz, 62.5 kHz, SF7.** The root default
  was previously the European preset. A device you flash fresh, or one that falls back to defaults,
  will come up on the US settings. If you are outside the US, set your region's parameters after
  flashing.
- The low-battery cutoff now debounces over 300 s rather than acting on a single ADC reading. A
  board that shut down early on a current spike should stop doing that.
- Companion frames are sized by what the BLE link actually delivers rather than by the buffer size,
  so a link that negotiates a smaller MTU no longer has frames built too large for it.
- The released V4 repeater image no longer carries a personal node identity.
