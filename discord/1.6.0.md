**Offband 1.6.0-beta1 is up** — pre-release, for testers. 221 commits since beta7.

**Offband now runs on a color touch screen.** The Heltec V4 TFT and V4-R8 TFT get a real on-device
interface: Home and Lock screens, Chats and conversations, a searchable Nodes list, a radar view on
the Map tab, and Settings. Messages are kept on the device through a reboot. You can compose on the
device, set notifications per channel, and use it in landscape. Add an SD card and it keeps an
archive — and a crash backtrace. Both GUI images ship with this release.

**Every color display now boots to the Offband lockup in color** — ST7735 panels and the rest, art
sized per panel rather than one size stretched to fit.

**The Heltec V4-R8 with the SAW filter is fully supported** — FEM/LNA control, TX LED, a power-off
that cuts FEM power, an observer env, and the board in CI so it can't quietly break.

**LilyGo T-Deck hardware works** — touch, keyboard, trackball, shared-bus radio. The image isn't
published yet; it needs bench time first.

**The Queen City Con badge makes sound.** A tone picker that auditions before you commit, six
chimes, eight slots for tunes you write on the badge, and per-channel tunes so you know which
channel is talking. GPS gets Off / On / Power-save modes — that's the fix for the battery cost
called out in beta7.

**beta7's known issue is fixed.** A USB companion streaming fewer contacts than it declared (350
declared, 344 streamed) — dropped frames went unreported when the TX FIFO filled. Fixed, and an
abandoned stream now complains on a stock build instead of only in a debug image.

**Security:** a malformed packet could overflow a stack buffer in MACThenDecrypt. Rejected now.

⚠️ **The default radio preset changed to the US standard — 910.525 MHz / 62.5 kHz / SF7.** It was
the European preset before. Flash fresh outside the US and you'll need to set your region's
parameters.

Full notes on the release page.
