📻 **Offband firmware v1.5.0-beta7** is out — pre-release, for testers.

🐕 **Every ESP32 node now has a watchdog. None of them did before.** The `startWatchdog` call sat inside an nRF52-only guard, so no ESP32 repeater or companion ever armed one — a hung node stayed hung until somebody power-cycled it. A hung main loop on any ESP32 board now reboots within 30 s and reports `reset_reason=TASK_WDT`. If you run a rooftop or solar repeater, this is the reason to take this build. nRF52 behaviour is unchanged.

🔌 **USB companions stop confusing a stock client.** Three paths were writing plain debug text into the framed companion protocol on `_usb` builds, so the client parsed an "unexpected frame type" per byte and settings rendered empty. Frames whose length lands on a 64-byte multiple also no longer stall waiting for the next write.

📡 **Observers can forward their logs to a syslog sink.** Wired on all six observer envs, sink stored in NVS so it survives a reboot, and the window can run until you switch it off. The capture ring is read through a cursor, so forwarding never eats what it forwards.

🔋 **Boot and shutdown lines say what they mean.** Every reset is named with why the board went down, the runtime is saved at shutdown, and a previous-boot runtime recovered from NVS now prints as a floor rather than pretending to be a measurement.

⌨️ **Queen City Con 0x4 badge support.** New board, CardKB keyboard, and standalone messaging on it — channel and DM sends with retries, a message store with unread counts, Messages as Home, and Contacts/Nearby/Status/GPS/Settings on the SW1 cycle. Badge binaries ship with the release, diag build included. **Treat it as under test** — its verification pass isn't finished.

⚠️ **Known issue, and it predates this build:** a USB companion can declare more contacts than it streams — a RAK 4631 declared 350 and sent 344–345. Whole frames get dropped when the TX FIFO fills and nobody checks the write result. Fix is in progress.

📁 **RC32 diag filenames changed:** `_testdiag` → `_diag`. If you pull RC32 diagnostic builds, the names differ from beta4–beta6.
